# AWS Email Forwarder

## Steps to set 

1. Create Bucket
2. Attach Bucket Policy
3. Create Lambda Function (python)
4. Add Lambda Permission
5. Add SES Sending permission
6. Zip Lambda Function
7. Upload Lambda Function
8. Create receipt rule set in aws
9. Create receipt rule in json
10. Upload receipt rule json to aws
11. Set rule set to active
12. Verify if email and domain are active
